# VISTA Interview Scheduling Assistant

A static website prototype for interview scheduling and candidate communication.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `vista-interview-assistant`).
2. Upload all files and folders from this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Notes

- This is a static HTML/CSS/JavaScript prototype. GitHub Pages can host it directly; React and a build step are not required.
- Demo login and application data are client-side only. Data may reset when the page reloads.
- Email sending and AI availability parsing are prototype/demo behaviours, not production integrations.
- Do not upload real candidate personal information. Add secure authentication, a backend, database rules and privacy controls before real-world use.
